Gerne, hier ist eine ausführliche Anleitung, wie du eine Fuzzy-Suche für deine Angebotsseite implementieren kannst. Wir verwenden die JavaScript-Bibliothek **Fuse.js**, da sie einfach zu integrieren ist und eine schnelle Suche direkt im Browser des Nutzers ermöglicht, ohne den Server bei jeder Tastenbetätigung belasten zu müssen.

### Das Konzept

1.  **Daten bereitstellen**: Wir übergeben alle Angebote, die von der PHP-Logik aus der Datenbank geholt werden, an das JavaScript im Frontend.
2.  **Fuse.js einbinden**: Wir fügen die Fuse.js-Bibliothek zu deiner Seite hinzu.
3.  **Suchlogik erstellen**: Wir schreiben ein JavaScript, das auf Eingaben im Suchfeld reagiert, die Angebotsdaten mit Fuse.js durchsucht und die Anzeige der Angebote auf der Seite in Echtzeit filtert.

---

### Schritt 1: Daten und HTML in `angebote.php` vorbereiten

Zuerst müssen wir sicherstellen, dass unser JavaScript weiß, welche Angebote es gibt und wie es die einzelnen Angebotskarten auf der Seite finden kann.

**1.1. Angebotskarten identifizierbar machen**

Öffne die Datei `php/projekt/angebote.php`. Finde die `foreach`-Schleife, die die Angebotskarten rendert. Wir müssen jeder Karte eine eindeutige ID geben, damit wir sie später per JavaScript ein- oder ausblenden können. Wir verwenden dafür ein `data`-Attribut und die ID des Angebots aus der Datenbank (ich nehme an, sie heißt `angebot_id`).

**Ändere diesen Code-Abschnitt:**
```php
// ALT
<?php foreach ($dataRows as $angebot): ?>
    <div class="angebot-card-wrapper">
        <?php require __DIR__ . '/partials/angebot-card.php'; ?>
    </div>
<?php endforeach; ?>
```

**Zu diesem:**
```php
// NEU
<?php foreach ($dataRows as $angebot): ?>
    <div class="angebot-card-wrapper" data-angebot-id="<?= htmlspecialchars($angebot['angebot_id']) ?>">
        <?php require __DIR__ . '/partials/angebot-card.php'; ?>
    </div>
<?php endforeach; ?>
```

**1.2. Angebotsdaten für JavaScript bereitstellen & Fuse.js einbinden**

Gehe nun zum Ende der Datei `angebote.php`. Kurz vor dem schließenden `</body>`-Tag binden wir Fuse.js ein und übergeben die `$dataRows` von PHP an eine neue JavaScript-Variable namens `allAngebote`.

**Ändere diesen Code-Abschnitt:**
```php
// ALT
<?php require __DIR__ . '/partials/footer.php'; ?>
<script src="scripts/app.js"></script>
</body>
</html>
```

**Zu diesem:**
```php
// NEU
<?php require __DIR__ . '/partials/footer.php'; ?>

<!-- Die PHP-Angebotsdaten in eine JavaScript-Variable umwandeln -->
<script>
    const allAngebote = <?= json_encode($dataRows) ?>;
</script>

<!-- Fuse.js Bibliothek von einem CDN einbinden -->
<script src="https://cdn.jsdelivr.net/npm/fuse.js/dist/fuse.min.js"></script>

<!-- Dein eigenes Skript, das wir in Schritt 2 anpassen -->
<script src="scripts/app.js"></script>
</body>
</html>
```

---

### Schritt 2: Die Suchlogik in `app.js` implementieren

Jetzt kommt die eigentliche Magie. Öffne die Datei `php/projekt/scripts/app.js` und füge den folgenden Code hinzu. Der vorhandene Code für das Benutzermenü kann einfach bestehen bleiben.

```javascript
// Warte, bis die Webseite vollständig geladen ist
document.addEventListener('DOMContentLoaded', function () {
    
    // --- Dein bestehender Code für das User-Menü bleibt hier ---
    const menu = document.querySelector('.user-menu');
    // ... (usw.)


    // --- NEUER CODE FÜR DIE FUZZY-SUCHE ---

    // Prüfe, ob wir auf der Angebotsseite sind (indem wir nach unserer Variable suchen)
    if (typeof allAngebote !== 'undefined') {
        
        // 1. Fuse.js konfigurieren
        const options = {
            keys: ['title', 'beschreibung'], // Die Felder, in denen gesucht werden soll
            includeScore: true, // Hilfreich zum Debuggen, zeigt an, wie gut die Übereinstimmung ist
            threshold: 0.4, // Wie "fuzzy" die Suche sein soll (0.0 = exakt, 1.0 = alles passt)
        };

        // 2. Fuse-Instanz mit den Angebotsdaten und Optionen erstellen
        const fuse = new Fuse(allAngebote, options);

        // 3. Referenzen auf die HTML-Elemente holen
        const searchInput = document.getElementById('search');
        const angeboteContainer = document.querySelector('.angebote-grid');
        const allAngebotCards = angeboteContainer.querySelectorAll('.angebot-card-wrapper');

        // 4. Event-Listener für das Suchfeld hinzufügen
        searchInput.addEventListener('input', function (e) {
            const searchTerm = e.target.value;

            // Wenn das Suchfeld leer ist, alle Angebote anzeigen
            if (!searchTerm) {
                allAngebotCards.forEach(card => {
                    card.style.display = ''; // Setzt den Anzeigestil zurück
                });
                return;
            }

            // Suche mit Fuse.js durchführen
            const results = fuse.search(searchTerm);
            
            // IDs der passenden Angebote extrahieren
            const matchingIds = new Set(results.map(result => result.item.angebot_id.toString()));

            // Alle Karten durchgehen und nur die passenden anzeigen
            allAngebotCards.forEach(card => {
                const angebotId = card.getAttribute('data-angebot-id');
                if (matchingIds.has(angebotId)) {
                    card.style.display = ''; // Karte anzeigen
                } else {
                    card.style.display = 'none'; // Karte ausblenden
                }
            });
        });
    }
});
```

### Zusammenfassung

Nachdem du diese Änderungen vorgenommen hast, passiert Folgendes:
1.  Wenn die `angebote.php` geladen wird, werden alle Angebotsdaten in die JavaScript-Variable `allAngebote` geschrieben.
2.  Das Skript in `app.js` erkennt diese Variable, initialisiert Fuse.js und bereitet alles für die Suche vor.
3.  Sobald du etwas in das Suchfeld (das in deiner `header.php` liegt) eingibst, durchsucht Fuse.js die Titel und Beschreibungen aller Angebote.
4.  Das Skript blendet dann sofort alle Angebote aus, die nicht zur Suche passen, und zeigt nur die relevanten Treffer an.

Das Ergebnis ist eine sehr schnelle, interaktive Sucherfahrung für deine Nutzer.
